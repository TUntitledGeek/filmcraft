What it takes from Premiere Pro

  • Dockable Workspace Freedom: Any panel can be undocked, floating, or split.
  • Multitrack Editing Hierarchy: V1-V8 and A1-A8 track patching and lock toggles.
  • Classic Tool Palette: V (Selection), C (Razor), B (Ripple), Y (Slip).
  • Dual Source/Program Paradigm: Mark In/Out on Source tape, insert directly to timeline.

What it takes from DaVinci Resolve

  • Lifecycle Page Switcher: Direct access to Cut, Edit, Color, Audio, and Deliver.
  • Charcoal & Warm Amber Aesthetics: Relaxing `#202126` panels with glowing `#be511b` highlights.
  • Crimson Red Precision Playhead: Standout visual needle for accurate frame alignment.
  • 3-Way Primary Color Wheels: Lift/Gamma/Gain grading with integrated scopes.

Why it feels better than both

  • No Clutter: Uncluttered task screens without Premiere's confusing dropdown sprawl.
  • No Rigidity: Unlike DaVinci's locked pages, you can still dock or customize panels if you want.
  • 120Hz Decoupled Scrubbing: Butter-smooth playback powered by WebCodecs & SIMD128.
  • Multiplayer Co-Op Ready: Figma-like real-time cursor presence built right in.
